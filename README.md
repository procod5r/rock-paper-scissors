# Rock, Paper, Scissors
A simple, interactive web-based game of the rock, paper, scissors where you play against the computer.

## How to Play
1. Open the project in your web browser.
2. Choose **Rock**, **Paper**, or **Scissors** by clicking on the respective button.
3. The computer will randomly choose its move.
4. The winner is determined by the standard rules:
   * Rock beats Scissors 
   * Scissors beats Paper 
   * Paper beats Rock

## Technologies Used
* HTML5
* CSS3
* JavaScript

## How to Run
To run this project locally on your machine:
1. **Clone the repository:**
   ```bash
   git clone https://github.com/procod5r/rock-paper-scissors
   ```
2. Navigate to the project folder.
3. Open the `index.html` file in your web browser.
